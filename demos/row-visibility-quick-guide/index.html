Storyblok / Quick guide

Show the right content.

Set language and country visibility on the Row. The rule applies to everything inside it.

Open your page > Body > Row > Visibility settings

Hide in this language

Select the language in the editor, then turn this toggle on. Turn it off to show the Row again, unless a country rule hides it.

Example: select Spanish and enable it to hide the Row in Spanish.

Hide in selected countries

Select the countries where the Row should not appear. Remove a country to show it there again, unless a language rule hides it.

Germany means Germany, not German-language Austria or Switzerland.

Before publishing: save and preview a hidden and a visible case. Check both the storefront country and language. If either exclusion matches, the Row is hidden.
Use Row controls, not legacy element-level Hide Country toggles. Try it in marvin-test (draft preview)
